# Practice Plans

This is the home for MacEwan Griffins practice plans. Each plan has its own page with the day's theme, blocks, install priorities, and special situations.

The Griffin agent generates these — when there's an upcoming opponent, a system to install, or a focus area for the week, just say "build me a practice plan for X" and a new file lands in this folder, then publishes here automatically.

## How plans are organized

- One file per practice (e.g. `2026-09-12-vs-lakeland.md`, `2026-10-03-zone-attack-install.md`)
- Newest plans appear at the top of the list
- Each plan follows the standard 5-block template (warm-up → install D → install O → special situations → conditioning)
