# Get Action

**One-line:** PG passes to a wing, then **sprints to set a ball-screen** for that wing.

## How it works
1. PG passes to wing on the slot
2. PG sprints to set a ball-screen on the wing's defender
3. Wing comes off into a downhill drive

## Why it works
- The pass-and-screen-away rhythm catches defenses napping
- The wing's defender has just defended the catch — now must navigate a screen immediately
- Empties the strong-side for the wing's drive

## Variations
- **Get + DHO** — instead of a pass, PG dribbles up and gives a DHO + sets the screen
- **Get + flare** — after the screen, PG flares for a kick-out 3
- **Get + slip** — PG slips the screen if defender hedges

## Defense counters
- **Switch the get** (best answer)
- **Show + recover** by the wing's defender to slow the drive
- **Top-lock the wing's catch** to disrupt the entry pass

### Verification notes (Claude)
- Mechanics (pass → sprint into ball screen for the passer, switch as best counter) are well-supported across glossaries and play libraries.
- The file does not assert an origin, which is good — "Get" terminology is widespread and not credibly attributable to one coach. Some sources associate the modern usage with the Spurs/Pop and with European coaches; I would not put a single name on it.
- The "Get + DHO" / "Get + flare" / "Get + slip" variation names are common in coaching circles but informal — different staffs use different labels.
