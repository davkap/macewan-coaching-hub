# Ram Screen

**One-line:** A screen-the-screener action: a small player screens for the screening big BEFORE the big screens for the ball.

## How it works
1. Big (5) starts at the FT line, prepping to set a ball-screen for PG
2. Wing (3) sprints from the corner and sets a screen on the 5's defender ("ram")
3. Now the 5's defender is dislodged — 5 sets the ball-screen with a clean angle and rolls free
4. PG attacks downhill with no help on the roll

## Why it works
The ram screen disconnects the big's defender from him before the ball-screen. By the time the ball-screen happens, the help structure is broken.

## Defense counters
- **Switch the ram screen** so the 5's defender stays with the 5
- **"Show ram" call** so defenders pre-fight for position
- **Don't top-lock the rammer** — let him through, then close on the actual ball-screen
