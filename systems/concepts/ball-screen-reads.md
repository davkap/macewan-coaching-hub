# Ball-Screen Reads (Concept Reference)

The ball-handler has 5 reads on every ball-screen. Coverage determines which one.

## Read 1 — Pull-up jumper
**Trigger:** big drops deep, guard fights over.
**Action:** ball-handler comes off the screen, rises into a mid-range or 3.
**Best vs:** drop coverage.

## Read 2 — Snake (back-to-middle)
**Trigger:** big drops, but in soft drop.
**Action:** ball-handler dribbles off the screen, then reverses direction back into the lane.
**Best vs:** soft drop, ICE.

## Read 3 — Pocket pass to roller
**Trigger:** big shows / hedges and the screener rolls hard.
**Action:** ball-handler delivers a pocket pass between defenders to the rolling big at the FT line.
**Best vs:** hedge, blitz.

## Read 4 — Skip / kick to weak-side shooter
**Trigger:** weak-side defender helps off shooter.
**Action:** skip pass to the corner or wing for an open 3.
**Best vs:** any coverage with weak-side tag.

## Read 5 — Reject the screen
**Trigger:** defense over-commits to the screen side (ICE, hedge).
**Action:** ball-handler refuses the screen and attacks the empty side.
**Best vs:** ICE, aggressive hedge.

## Screener reads
- **Roll** — defender drops or hedges late → roll to rim
- **Pop** — defender drops far → pop for the 3
- **Slip** — defender hedges early → slip before contact
- **Ghost** — defender pre-switches → fake screen + pop
- **Re-screen** — defender recovers → screen again immediately

## Coverage cheat-sheet
| Coverage | Best read |
|----------|-----------|
| Drop | Pull-up jumper |
| Soft drop | Pocket to roller |
| Hedge | Pocket to roller; or split |
| Switch | Mismatch attack |
| Blitz | Short roll → 4-on-3 |
| ICE | Reject or step-up screen |
| Weak (under) | Pull-up 3 |

### Verification notes (Claude)
- The five-read framework (pull-up, snake, pocket, skip, reject) plus screener reads (roll, pop, slip, ghost, re-screen) is standard coaching vocabulary and matches Wikipedia and every major coaching site, but I could not surface a single canonical article that lists exactly these five in this order — coaches frame it differently (some use 4 reads, some 6).
- "Snake dribble" attribution is sometimes credited to Chris Paul in popular media; the technique itself predates him. Treat the player attribution loosely.
- "ICE" coverage (force-down/force-baseline) is generally credited to Tom Thibodeau (Bulls/Celtics era) — this could not be hard-verified from a primary source in this pass; flagged as commonly accepted but anecdotal.
- The coverage cheat-sheet's "best read" mappings are sound rules of thumb but are not from a single sourced authority.
