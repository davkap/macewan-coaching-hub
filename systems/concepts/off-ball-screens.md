# Off-Ball Screens (Concept Reference)

The screen types every coach should be able to identify on film and defend by name.

## Down-screen
- Big screens **down toward the baseline** for a wing/guard cutting up
- Cutter pops to the wing or top
- **Defense:** chase over, top-lock if shooter

## Pin-down
- Cousin of down-screen — usually screened from the elbow for a corner shooter
- Cutter pops to the wing
- **Defense:** chase over, switch if no shooting threat

## Back-screen
- Screener sets a screen BEHIND the cutter's defender (defender doesn't see it coming)
- Cutter goes backdoor to the rim or pops to a different spot
- **Defense:** call out "BACK!" — switch is usually the answer

## Flare-screen
- Screener sets a screen so the cutter can flare AWAY from the ball for a kick-out 3
- **Defense:** switch, or "TOP" the screen

## Cross-screen
- Screen across the lane (typically at the post for a big)
- **Defense:** switch or fight over, depending on size

## Stagger-screen
- Two consecutive screens for the same cutter
- **Defense:** switch the second screen at minimum

## Elevator-screen
- Two screeners stand shoulder-to-shoulder; cutter goes between them as they close like elevator doors
- Almost always for a shooter, almost always an ATO
- **Defense:** switch one of the doors, or top-lock pre-action

## Veer-screen
- A back-screen on the help defender (instead of a primary defender)
- **Defense:** switch or pre-call

## Universal off-ball defense rules
1. **Talk first** — call out the screen type before contact
2. **Top-lock shooters** — make them go the long way
3. **Switch like-sized matchups** — fight over for the rest
4. **Tag big-to-big screens** — big screens for big = bad mismatches downstream

### Verification notes (Claude)
- "Elevator screen" gained NBA-wide popularity through Steve Kerr's Warriors using it for Klay Thompson and Stephen Curry (post-2014). Often-cited primary example: Game 6 of the 2014 Eastern Conference Finals (Heat–Pacers) and Warriors playoff runs. Solid attribution.
- "Veer screen" terminology varies — some programs use "veer back-screen" specifically for a back-screen on the help defender during a drive; others use "veer" for any redirect screen. Treat the term as program-specific.
- No claims appear factually wrong, but the defensive prescriptions ("switch like-sized matchups", "top-lock shooters") are general best-practice rather than from a single canonical source.
