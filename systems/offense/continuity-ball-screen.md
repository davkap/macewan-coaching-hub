# Continuity Ball-Screen Offense

**Family:** ball-screen offense that **flows from one ball-screen into another** automatically — no reset needed.

## Spacing
4-out-1-in or 5-out. The big sets ball-screens repeatedly across multiple possessions or trips.

## Core principle
**Every action ends in another action.** PG comes off a ball-screen → if no shot, big sets again on the other side. Or, big sets a screen → rolls → another big lifts to set the next screen.

## Common continuity patterns
- **Ball-screen → DHO → ball-screen** (chain on chain)
- **Drag → step-up → drag** across both sides of the floor
- **Loop:** PG comes off, kicks weak side, sprints around an off-ball screen for the return ball-screen

## Why coaches like it
- Defense can't reset between possessions — pressure mounts
- Simple to teach — same action, repeating
- Hides limited playbook depth

## Counters / answers (for defense)
- **Switch every screen** to break continuity
- **Pre-call coverage** so bigs aren't surprised
- **Pressure the kick-out** — disrupt the rhythm pass

## Scout signals
- Multiple ball-screens per possession
- Same continuity pattern over and over
- Big stays in screening rotation (doesn't post)

## Famous practitioners
- Many NCAA and U Sports programs use a flavor of this
- Brad Stevens (Butler era)

### Verification notes (Claude)
- "Continuity ball-screen offense" is a coaching-vernacular label, not a single trademarked system — there is no canonical written source defining it precisely. The patterns described (chain-chain, drag/step-up, loop) are widely taught but not standardized.
- Brad Stevens at Butler ran motion and ball-screen sets, but calling Butler a "continuity ball-screen" program is a stretch — his Boston Celtics offense fits the description better. Coach should consider whether to keep that example.
- Loyola Marymount's association with this family is more about Westhead-era pace than continuity ball-screen specifically; the connection is loose.
